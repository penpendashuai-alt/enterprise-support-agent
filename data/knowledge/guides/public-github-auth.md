# GitHub 官方认证方式摘要

## 公开资料摘要

GitHub 可通过浏览器、命令行或 API 访问，不同入口使用相应认证方式。HTTPS Git 操作可使用个人访问令牌或凭据管理工具；SSH 使用 SSH 密钥。组织采用 SAML SSO 时，访问组织资源可能还需要身份提供商认证。此处是公开文档摘要，不代表演示企业已启用特定设置。

## 使用范围

源页面：GitHub Docs 的 About authentication to GitHub。内容由项目自行概括；具体可用方式以账号类型、组织配置和原始文档为准。不要把 GitHub 账号密码直接当作 Git HTTPS 的密码认证方案。
