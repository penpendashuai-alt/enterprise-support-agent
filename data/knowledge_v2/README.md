# Enterprise Support 知识语料

Synthetic enterprise support dataset / public technical documentation。

共 36 篇：34 篇自行编写的演示制度、操作或排障指南，以及 2 篇带原始 URL 和获取日期的公开技术文档摘要。它们不是实际企业内部制度。每篇来源、版本和使用依据见 manifest.json；仅入库清单文件，不扫描整个仓库。Phase 5 新增相近故障、权限细节、冲突和受控恶意文本；冲突材料不代表真实生效制度，恶意文本只作检索数据，不授权任何工具操作。

本数据集随项目 MIT 许可证发布；公开页面的原始内容版权仍归原作者，本项目仅提供自行编写的简短摘要与归属链接。语料版本 synthetic-support-v2。原 data/knowledge 及 Phase 4 报告保持原样；双索引统一读取 evaluation/datasets/snapshot_v2.json 的同一份分块快照。

演示工单默认 P3，用户指定值需明确展示，所有创建都必须批准；不存在承诺的响应 SLA。文档不授权真实系统操作。
